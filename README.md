# Web-Based Equipment Failure Prediction System

Веб-система прогнозування поломок техніки на основі історії ремонтів.

## Компоненти системи:
1. **server** - Node.js / Express бекенд
2. **client** - React.js / Vite фронтенд
3. **ml-service** - Згорткова нейромережа (Random Forest) на базі Python (Flask)

## Запуск проекту (Локально)
1. Встановіть залежності у папках \`server\` та \`client\`.
2. Встановіть Python залежності у \`ml-service\` (\`pip install -r requirements.txt\`).
3. Використовуйте \`npm run dev\` на клієнті та сервері. Питон сервер запускається через \`python app.py\`.
